# Business Case

## Decision problem

Portfolio and watchlist monitoring often fails because analysts show price charts without answering the operational questions behind them:

- Which names have actually created the most value?
- Which names carry the largest downside history?
- Which securities are highly correlated?
- Is volatility currently elevated relative to each security's own history?
- Does the forecasting model beat a simple benchmark?

## Analytical solution

The system converts raw market history into:

1. validated daily price facts,
2. performance measures,
3. volatility and drawdown measures,
4. return-correlation analysis,
5. technical monitoring features,
6. forecast ranges,
7. walk-forward model evaluation.

## Decision outputs

The Power BI layer should support:

- watchlist prioritization,
- risk review,
- concentration monitoring,
- volatility alerts,
- historical performance comparison,
- model-quality monitoring.

## Important boundary

This is a monitoring and analytics system.

It should **not** be marketed as an automated trading strategy, investment adviser or guaranteed forecasting engine.
